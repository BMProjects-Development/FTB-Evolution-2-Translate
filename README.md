# Установка перевода сборки FTB Evolution 2

В данном небольшом руководстве мы описали инструкции для установки перевода FTB Evolution 2 двумя способами!

## Важная информация
- Версия Minecraft для сборки 26.1.2 
- Загрузчик модов NeoForge 26.1.2.121
- Перевод создан для версии сборки 1.4.1 (вполне вероятно на других версиях он тоже будет работать, но могут возникать ошибки)
- Авторы перевода [BMProjects](https://t.me/BMProjects) (в тг канале можно задавать вопросы по переводу)

## Способ 1 - Установка с нуля:
1. Скачайте архив с полным переводом [Google Drive](https://drive.google.com/file/d/1LHHbXzqYNcEFGhonjht-i5j8syu694S9/view?usp=drive_link)
2. Очистите папку .minecraft
3. Перенесите все папки из архива в .minecraft
4. Запустите игру
5. Приятной игры!

## Способ 2 - Установка в уже имеющуюся сборку:
1. Скачайте архив с только переведёнными элементами [Google Drive](https://drive.google.com/file/d/1AMdWZCncDBF5txHgcZAPy0X_c1lBpwdg/view?usp=drive_link)
2. Перенесите папки config, kubejs, resourcepacks с заменой в папку где находится установленная сборка
3. Запустите игру
4. Приятной игры!
