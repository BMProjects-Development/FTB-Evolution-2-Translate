<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">Running a Cross</Color>
</Column>

* Switch the <ItemLink id="ftbic:advanced_hydroponic_accelerator"/> to Mutation mode. Lanes 1 and 2 cross with each other, and so do lanes 3 and 4.
* Put one parent seed and a soil in each lane of the pair. The cross runs at the speed of the slower soil.
* Every attempt uses 500 mB of water and one seed from each parent slot.
* A <Color id="green">success</Color> puts the new seed in the first lane's output and uses up both parents.
* A <Color id="red">failure</Color> hands both parents back, one into each lane's second output slot.
* Crosses take 20 s to 60 s on dirt. Parallel Processing Upgrades run several attempts at once when each parent slot holds enough seeds.

<ItemImage id="minecraft:air" scale="0.25"/>

<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">Where the Tree Starts</Color>
</Column>

These seeds are never the result of a cross, so craft them at the Infusion Altar: Air, Earth, Enderman, Fire, Ghast, Nickel, Sapphire, Silver, Soulium, Squid and Water.

From those, everything can be bred except Diamond, Electrum, Emerald, Gold, Iridium, Netherite, Platinum and Soularium. Each of these needs a parent from the same group. Craft one seed from each pair at the altar and the rest open up: Diamond or Emerald, Electrum or Gold, and Iridium or Platinum.
