  # <Color id="gold">Data Models</Color>

  <ItemImage id="hostilenetworks:blank_data_model" scale="2"/>

</Column>

Power is per tick for one model in a Data Center. Each drop listed is one possible choice per 15 second cycle, not all of them at once.
