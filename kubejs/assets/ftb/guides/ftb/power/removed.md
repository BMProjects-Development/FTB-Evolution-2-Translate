<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">Generators</Color>
</Column>

<ItemImage id="minecraft:air" scale="0.25"/>

| Generator | What happened |
|---|---|
| <ItemImage id="energizedpower:coal_engine"/> Coal Engine | Removed. Recipes that used it take a Basic Machine Frame instead. |
| <ItemImage id="ironfurnaces:augment_generator"/> Generator Augment | Its recipe is removed, so furnaces can't be turned into generators by crafting. The only source is the Furnace Pouch loot crate the Gambler sells. |
| <ItemImage id="justdynathings:ferricore_solar_panel"/> Just Dyna Things solar panels | All four tiers removed: Ferricore, Blazegold, Celestigem and Eclipse Alloy. |
| <ItemImage id="powah:reactor_starter"/> Powah Starter and Basic Reactors | Removed. Reactors start at Hardened, which has its own recipe. |
| Powah Starter and Basic Thermo Generators | Removed. Thermo Generators start at Hardened, which takes a Magma Block in place of the Basic one. |
| <ItemImage id="colossal_reactors:red_cake"/> Red Cake | No longer a Colossal Reactors fuel. |

<ItemImage id="minecraft:air" scale="0.25"/>

> <Color id="yellow">Existing Starter and Basic Powah Reactors and Thermo Generators only make 1 FE/t.</Color>

<ItemImage id="minecraft:air" scale="0.25"/>

  ## <Color id="gold">Stellaris Oil Deposits</Color>
</Column>

<ItemImage id="minecraft:air" scale="0.25"/>

Stellaris no longer hides oil under random chunks. Oil comes from Oritech oil wells and oil lakes, and it is all Oritech Crude Oil. See [Other Mods](other_mods.md).
